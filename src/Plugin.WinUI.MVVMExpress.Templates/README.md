# Plugin.WinUI.MVVMExpress.Templates

`dotnet new` templates for **Plugin.WinUI.MVVMExpress**.

```bash
dotnet new install Plugin.WinUI.MVVMExpress.Templates
dotnet new winui-mvvmexpress -n MyApp
dotnet new winui-mvvmexpress-page -n Catalog --namespace MyApp
```

This is not Plugin.Maui.MVVMExpress.Templates. There is no Shell — use a `Frame` named `NavigationHost`.

NuGet: https://www.nuget.org/packages/Plugin.WinUI.MVVMExpress.Templates
GitHub: https://github.com/nuvyntralabs/Plugin.WinUI.MVVMExpress
