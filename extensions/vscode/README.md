# WinUI MVVMExpress for VS Code

Installs `Plugin.WinUI.MVVMExpress.Templates` and runs `dotnet new winui-mvvmexpress` / `winui-mvvmexpress-page`.

Commands:

- **WinUI MVVMExpress: Create New App**
- **WinUI MVVMExpress: Add Page**

This is not the MAUI MVVMExpress extension. Marketplace upload is manual from the `ide-extensions` workflow artifact.
